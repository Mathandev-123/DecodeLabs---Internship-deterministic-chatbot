Deterministic Logic Chatbot Engine

A Python-based deterministic chatbot developed using rule-based logic and explicit control flow.

Features

- Input sanitization
- Rule-based intent recognition
- Greeting detection
- Exit handling
- Guardrail and safety responses
- Continuous chatbot interaction loop

Technologies Used

- Python 3

Project Purpose

This project was developed for DecodeLabs Internship Milestone 1 to demonstrate deterministic AI architecture instead of probabilistic AI systems.

Run the Project

python chatbot.py
